# 双臂 0.80 m / 障碍臂 0.25 m/s 轨迹与视频

2026-09-20 仿真记录。左臂深入参考峰值为 **0.25 m/s**，两基座中心距 **0.80 m**。
右臂使用 RA-CBF（Reachable + Fresh）避障，完整执行 **36 s**。

- [MP4 视频](racbf_base0p8_0p25mps.mp4)：1920×1080、60 fps、原速播放，包含深入、停留、回撤和保持。
- [关节轨迹 CSV](joint_trajectory.csv)：36001 帧、1 ms 间隔；含时间及左右臂各 7 关节的位置和速度。
- [末端轨迹 CSV](end_effector_trajectory.csv)：时间及左右臂末端世界坐标，单位 m。
- [完整状态 NPZ](trajectory.npz)：关节位置、速度、加速度、力矩、参考量、末端位置及间距记录。
- [对比曲线](clearance_comparison.png)、[详细结果](RESULTS.md)、[核验数值](comparison_validation.json)。

CSV 第一列为时间（s），随后为左臂 joint1–7 和右臂 joint1–7 的位置（rad），
最后为相同顺序的速度（rad/s）。以文件表头的关节名为准。
NPZ 的 `qpos`、`qvel` 均采用左 7 关节、右 7 关节顺序。
末端世界坐标原点在双基座中点，+X 指向右侧基座，+Z 向上。

本次仅将原 0.1 m/s 实验的深入时间缩放参数从 5 改为 2。
完整深入路径约 69.82 cm；终点停留 1 s；回撤参考峰值保持 0.08 m/s。
控制器仍采用最近 7 对跨臂约束、安全距离 50 mm、Z=1、rho=0.6，关闭 QP 自碰撞约束。
